# Security Policy

## Supported Versions

CodeVeto is currently in early development (System Design Phase). Only the
`main` branch is supported for security fixes at this time.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in CodeVeto, please **do not** open
a public issue.

Instead, report it privately using GitHub's [private vulnerability
reporting](https://github.com/Ahmed-Abdulqader/CodeVeto/security/advisories/new)
feature (Security tab → Report a vulnerability).

Please include:
- A description of the vulnerability and its potential impact
- Steps to reproduce, or a proof-of-concept if possible
- Any relevant logs, code snippets, or configuration

You can expect an initial response within a few days. Confirmed
vulnerabilities will be addressed as a priority, and credit will be given
in the fix's release notes unless you prefer to remain anonymous.
